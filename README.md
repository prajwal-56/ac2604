# Accessible Coconut 26.04 — Build Documentation

---

## About This Documentation

This documentation records the work done porting **Accessible Coconut** — an accessibility-focused Ubuntu MATE derivative designed for visually impaired users — from its 22.04 release to a **Kubuntu 26.04** base.

---

## Documentation Structure

The documentation is organized into the following sections:

| Document | Description |
|---|---|
| [**01. Overview**](01-overview.md) | Architectural choices, Kubuntu base rationale, KDE-to-MATE conversion process, and testing methodologies. |
| [**02. Fixes & Customizations**](02-fixes-and-customizations.md) | Verified fixes: Calamares installer, panel layout, Marco keyboard shortcuts, IBus-Braille, Orca autostart & login, casper fixes, branding, and bundled applications. |
| [**03. Known Issues**](03-known-issues.md) | Unresolved items tracked before release: GRUB post-install branding, installer speech voice, and unavailable packages. |
| [**04. Technical Learnings**](04-technical-learnings.md) | Critical technical gotchas and lessons covering Cubic, Casper, initramfs, dconf keyfiles, and MATE schema behavior. |
| [**05. Tools & Resources**](05-tools-and-resources.md) | Tools and reference environments used across the build and testing workflow. |
